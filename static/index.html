Get started

Up and running in two steps.

  1. Add the skill

    npx skills add mwmdev/slashmail

    Works with Claude Code, Codex, Cursor and more.

  2. Ask your agent

    Set up slashmail for my Gmail account.

    It installs slashmail, writes your config, and asks you to save your password yourself.

Set up by hand

  1. Install

    cargo install slashmail

    Or download a binary:

    Linux
    x86_64 ARM64
    Mac
    Apple silicon Intel
    Win
    x86_64

  2. Add your account

    Create a config file:

    Linux
    ~/.config/slashmail/config.toml
    Mac
    ~/Library/Application Support/slashmail/config.toml
    Win
    %APPDATA%\slashmail\config.toml

    Fill in your account settings:

    host = "imap.gmail.com"
tls = true
user = "you@gmail.com"

  3. Set your password

    export SLASHMAIL_PASS="your-password"

    Or save it in a .env file next to config.toml:

    SLASHMAIL_PASS="your-password"

    Or leave it unset and enter it when asked.

    Gmail
    Use an app password, not your Google password. Requires 2-Step Verification.
    Yahoo
    Use an app password from your account security settings.
    iCloud
    Use an app-specific password from your Apple Account.
    Proton
    Use the password shown in Proton Mail Bridge.
    Outlook
    Not supported yet: Microsoft no longer accepts passwords over IMAP.

  4. Ready

    slashmail status

    Lists your folders with message counts.

The complete command set

Your inbox toolbox

Focused commands that compose cleanly in your terminal, scripts, and agent workflows.

Get started ↓
draft

Save a new plain-text or HTML draft with recipients and attachments.

reply

Build a threaded reply-all draft from one message UID.

attachments

List or save attachments from one message UID.

search

Find messages by sender, recipient, text, date, size, or state.

read

Display matching messages, or one exact message by UID, in the terminal or as JSON.

delete

Move filtered messages to Trash, with a dry-run mode first.

move

Move filtered messages into another mailbox folder.

export

Save matching messages locally as portable .eml files.

mark

Set read, unread, flagged, or unflagged state in bulk.

count

Count matching messages quickly without fetching their content.

quota

Check current mailbox storage usage and capacity.

status

See message and unread totals for every folder.

completions

Generate completions for Bash, Zsh, Fish, PowerShell, or Elvish.

Privacy

Your mail, your machine.

Slashmail

Runs locally and talks only to your IMAP server. No telemetry, no account, no cloud service.

Connection

TLS 1.2+ with certificate checks for every remote server.

Credentials

Read from an environment variable, a .env file beside your config, or a prompt.

Draft only

Saved to the Drafts folder on your own mail server. Slashmail has no way to send.

AI agents

When your LLM agent runs read, its provider receives the full message. For confidential mail, use slashmail with a local LLM model.

This site

No analytics, tracking scripts, or third-party requests.
