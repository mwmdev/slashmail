Tutorial

Use slashmail with Gmail.

slashmail signs in to Gmail over IMAP with an app password: a password for slashmail alone, which you can revoke without changing your Google password.

You need

  • A Gmail account, or a Google Workspace account whose admin allows IMAP for any mail client
  • 2-Step Verification on your Google Account
  • slashmail installed (get started)

  1. Turn on 2-Step Verification

    App passwords need it. If it's off, turn it on under Security in your Google Account. IMAP itself is always on in Gmail.

  2. Create an app password

    Open myaccount.google.com/apppasswords, create one named slashmail, and copy it. Google shows it only once.

    If Google says app passwords aren't available, your account signs in with security keys only, has Advanced Protection, or belongs to a work or school that doesn't allow them.

  3. Point slashmail at Gmail

    Create a config file:

    Linux
    ~/.config/slashmail/config.toml
    Mac
    ~/Library/Application Support/slashmail/config.toml
    Win
    %APPDATA%\slashmail\config.toml

    Use your Gmail address:

    host = "imap.gmail.com"
tls = true
user = "you@gmail.com"
trash_folder = "[Gmail]/Trash"

    trash_folder tells slashmail delete where Gmail keeps deleted mail. slashmail finds the Drafts folder by itself.

  4. Save the password

    Create a .env file next to config.toml with the app password, and keep it readable only by you:

    SLASHMAIL_PASS="your-app-password"

  5. Check the connection

    slashmail status

    You should see your labels as folders, and Gmail's own folders under [Gmail]/:

Labels and folders

In GmailIn slashmail
A label--folder "Clients"
A nested label--folder "Clients/Acme"
Sent--folder "[Gmail]/Sent Mail"
All your mail, archived included--folder "[Gmail]/All Mail"
Every label at once--all-folders lists each message once, from INBOX when it's there. It skips All Mail, Spam, and Trash.

A message with three labels sits in three folders, but it's still one message: mark --read marks it read in all of them. delete moves it to Trash, which Gmail empties after 30 days.

Troubleshooting

[AUTHENTICATIONFAILED] Invalid credentials
Gmail rejected the address or the password. Use an app password, not your Google password; changing your Google password revokes your app passwords. On a work or school account, your admin must also allow IMAP for any mail client.
IMAP connections to non-loopback hosts require TLS
Add tls = true to config.toml.
Folder 'Trash' does not exist
delete is looking for a folder named Trash. Set trash_folder to the Trash folder that slashmail status lists.
