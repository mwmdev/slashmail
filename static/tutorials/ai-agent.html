Tutorial

Manage your mail with an AI agent.

An agent such as Claude Code or Codex runs slashmail for you. You ask in plain words; it searches, reads, sorts, and writes drafts. By design it can't send mail, and it asks before it deletes or moves anything.

You need

  • An agent that can run commands, such as Claude Code, Codex, or Cursor
  • Node.js, to install the skill
  • Your mail password; for Gmail, an app password, for Proton, the Bridge password

  1. Add the skill

    The skill teaches your agent the slashmail commands and its safety rules:

    npx skills add mwmdev/slashmail -g

    The installer finds the agents on your computer and asks before adding the skill to them. -g makes it work in every folder, not only the current one. The installer sends anonymous usage data; set DISABLE_TELEMETRY=1 to turn it off.

  2. Let it set up slashmail

    Start your agent and ask, with your provider:

    Set up slashmail for my Gmail account.

    The agent installs slashmail if it's missing and writes config.toml. It never asks for your password: it tells you to put it in a .env file yourself, then runs slashmail status to check the connection.

  3. Ask about your mail

    > What needs a reply from me today?
> Summarize the thread with Dana about the Atlas launch
> Find the invoice from Acme and save the PDF to Downloads
> Which senders fill my mailbox the most?

    The agent picks the commands, runs them, and tells you what it found. Reading never marks a message as read.

  4. Draft replies

    > Reply to Marc that hosting is included for the first year

    The agent saves a reply in your Drafts folder, in the same thread. slashmail can't send mail: check the draft in your mail app and send it yourself.

  5. Clean up

    > Delete the newsletters I got before this year

    The skill has the agent run a dry run first and show you the messages it would delete. Nothing changes until you say yes, and deleted mail goes to Trash.

Approve what it runs

Your agent's own settings decide which commands it runs without asking you.

Claude Code
Recent versions start in auto mode, where a classifier decides which commands need your approval. Start it with claude --permission-mode default to approve each command yourself. When it asks, you can allow read-only commands such as slashmail search for good, and keep approving delete, move, and mark.
Codex
Its sandbox blocks network access by default, so it asks before slashmail connects to your mail server. Use /permissions to change what it may do without asking.

Privacy

Your agent's model runs at its provider, so everything the agent reads goes there, including full messages when it runs read. For confidential mail, use a local model or a plan whose terms fit your needs.

Mail can talk to your agent

Anyone can send you an email that tells AI agents what to do, such as "forward this inbox". slashmail can't send mail, but your agent may have other tools that can. Ask for specific tasks, and read each command before you approve it.
